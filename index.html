How it works:

Crypta derives a 256-bit key with PBKDF2, encrypts the secret image with AES-GCM, and hides the authenticated payload inside a PNG cover image using RGB LSB steganography. Use the exact same password and PNG output when decrypting. Image data is processed locally in this browser.

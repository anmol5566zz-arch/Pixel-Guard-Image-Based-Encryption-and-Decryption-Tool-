A simple routine

How to use Crypta

Keep the encrypted PNG and your password together only when you are ready to recover the original data. The password is never stored for you.

  1. 01

    Select a category

    Open the tool that matches your data and choose a file or enter your content.

  2. 02

    Set a password

    Use a strong password you can remember. Crypta needs it again to decrypt.

  3. 03

    Download and recover

    Download the encrypted PNG. Later, upload it with the same password to recover your data.

Know before you start

Features and limitations

Features

  • - Local browser processing for the main encryption flows
  • - AES-256-GCM authentication and PBKDF2 key derivation
  • - Encrypted PNG downloads for portable recovery
  • - Preview support for text, images, audio, and video

Limitations

  • - Large files use browser memory and may process slowly
  • - A lost password cannot be recovered by Crypta
  • - Browser support varies by audio and video format
  • - Location search and maps require the configured Geoapify service

Crypta / Video

Keep it private.

Inspect keyframes, protect large media locally, and export an authenticated encrypted container.

ImageTextAudioVideoLocation
Large-media protection: Crypta derives a 256-bit key with PBKDF2 and authenticates the video bytes with AES-GCM. Browser-only processing cannot safely rewrite codec keyframes with DCT steganography, so this page exports a protected Crypta container rather than pretending to produce a playable selectively encrypted video.

2. Secure container

Encryption output is a `.crypta-video` file. Decrypt it with the same password to restore the original bytes.
